Example reports

Produced by one unattended run of the Measure QA Community Harness on an anonymised Power BI marketing report, plus a second run against a copy of it with one column deliberately rebound. Nothing on these pages was written by hand.

Demo copy: the screenshots are downscaled for the web and the report's internal file name is replaced, so this bundle no longer matches the evidence manifest of the sealed case it came from. The case itself is unchanged. No decision has been recorded on the sign-off pages — they are shown as an analyst first receives them.

  • /analytics-qa:investigate
    How it works

    How the dashboard is actually built: page by page, the label on screen, the measure behind it, the tables that measure reads, where those tables come from, and which filters reach which visual. 16 pages, 252 visuals, 40 of 171 measures actually used.

    For whoever inherited the report
  • /analytics-qa:detect
    Findings

    What is wrong with it: 4 defects worst first, 11 open questions, 7 model-lint flags and the 17 checks that passed — each with the question that settles it.

    For whoever has to fix it
  • /analytics-qa:capture
    Sign-off page

    What the screen showed in each situation, which checks hold, and the questions an analyst has to answer — with Sign off and Reject per component. Click any screenshot.

    For the analyst or stakeholder who signs
  • /analytics-qa:capture
    Capture report

    The sealed record behind every claim: screenshots, observations, receipts, queries and limitations. This is what the next regression is measured against.

    For an auditor, or for the agent asked to fix it
  • /analytics-qa:regress
    Regression report

    One column of one table was rebound without telling the session. It found the single changed visual, proved the consequence at both layers, and classified every baseline expectation: 3 new regressions, 14 preserved, 15 still open.

    For the person approving a change
