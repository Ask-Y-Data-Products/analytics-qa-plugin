Example reports

One marketing dashboard, four problems, and the reports the harness produced about it — then a fix, and the regression run that checked the fix.

The dashboard is an ordinary-looking Power BI page over an anonymised data set: a total leads card, leads by channel, a Meta platform-versus-CRM comparison, spend by campaign. Four things are wrong with it and none of them is visible at a glance. Everything below was produced by unattended agent runs; nothing on these pages was written by hand.

Demo copy: the screenshots are downscaled for the web and the report's internal file name is replaced, so this bundle no longer matches the evidence manifest of the sealed case it came from. The case itself is unchanged. The decisions shown on the capture report were recorded for this demonstration and are not a business approval.

  1. /analytics-qa:investigate
    How it works

    How the page is actually built. Follow one number from the card on screen, to the measure behind it, to a plain sentence of what that measure does, to the tables it reads, to the warehouse table underneath — with flags where a measure reads the machine clock or drops a filter.

    For whoever inherited the report
  2. /analytics-qa:detect
    Findings

    What is wrong with it: six defects worst first, eight open questions and seven model warnings, each with what we saw, why it matters and where.

    For whoever has to fix it
  3. /analytics-qa:capture
    Sign-off page

    What the screen showed in each situation, which checks hold, and the questions to answer — including "the bar chart hides 2,006 leads the table next to it shows; is that intentional?" Sign off or reject, per part of the page.

    For the analyst or stakeholder who signs
  4. /analytics-qa:capture
    Capture report

    The sealed record behind every claim, with the reviewer's own decisions and comments folded in. This is what the next regression is measured against.

    For an auditor, or for the agent asked to fix it
  5. /analytics-qa:regress
    Regression report

    Two of the four problems were fixed by an agent reading the findings. This is what the replay found: two defects fixed, four still open, sixteen expectations preserved — and one new regression, because removing a filter exposed $18,400 of spend on a campaign with no name.

    For the person approving a change
